## 建模约束

按 `style/niulai.toml` 的 `[shading]` 来，但有几条得在建模阶段就守住，
后期 `degrade.py` 补不回来：

1. **不倒角。** 一条 bevel 都不要。边就是要硬。
2. **不细分。** `degrade.py` 会把 SUBSURF / BEVEL / SMOOTH 修改器删掉，
   但如果你已经 apply 了，删不掉，只能重做。
3. **面数控制在 300 以内。** 超过 500 会被 decimate 砍到 35%，砍出来的形状不可控。
4. **一个材质一个纯色。** 不要贴图，不要法线贴图，不要粗糙度贴图。
5. **原点放脚底**，也就是世界原点 `(0,0,0)`。分镜里的 `loc` 是站立位置。
   代理由 `_origin_to_base()` 自动归零，资产得你自己摆好。
6. **不做骨骼。** 关键帧打在整个物体上，四肢不单独动。牛来 就是这么做的。
7. **五官、头发、装饰一件都不能省。** 这条和上面六条方向相反，别搞混：
   前六条是「别做精细」，这条是「必须做」。没脸的方块人是占位符，不是风格。
   歪、不对称、比例不对都行，就是不能没有。详见 `docs/NIULAI_LOOK.md` 第 0 条。

## 代理已经支持的脸

`humanoid` 代理给 `face` 就长脸，不给就是个没脖子的方块人（远景杂役够用）：

```yaml
proxy:
  kind: humanoid
  height: 1.62
  color: [0.62, 0.48, 0.36]
  face:
    eyes: true            # 眼白一个球，眼珠一个小球，两只不一样大
    brows: true           # 两条厚白块，一条平一条翘
    nose: true
    hair: elder           # none | plain | elder（elder 多两鬓）
    beard: long           # none | short | long，六棱台
    hair_color: [0.93, 0.93, 0.91]
```

爷爷现在 204 个面，在三百以内。加零件的时候留意这个数。

## 为什么可以不急着建

代理和成品在这套画质规格下差别不大 —— 这不是安慰话，是规格决定的：
平面着色、纯色材质、零反弹光照之下，一个方块拼的人和一个精心建的人，
渲出来的差距远小于常规流水线。所以分镜、运镜、节奏可以先跑通，资产后补。
