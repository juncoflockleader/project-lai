# 角色资产

一个角色一个 `.blend`，文件里的物体名要和分镜 YAML 里的 `subjects[].name` 一致，
否则 `build_subject()` 只会取文件里的第一个物体。

| 文件 | 对应 | 状态 |
|---|---|---|
| `yeye.blend` | 爷爷 | 没建，跑积木代理 |
| `chuanshanjia.blend` | 穿山甲 | 没建，跑积木代理 |
| `shejing.blend` | 蛇精 | 没建，跑积木代理 |
| `xiezijing.blend` | 蝎子精 | 没建，跑积木代理 |
| `huluwa1.blend` … `huluwa7.blend` | 七个葫芦娃 | 没建 |

## 建模约束

按 `style/niulai.toml` 的 `[shading]` 来，但有几条得在建模阶段就守住，
后期 `degrade.py` 补不回来：

1. **不倒角。** 一条 bevel 都不要。边就是要硬。
2. **不细分。** `degrade.py` 会把 SUBSURF / BEVEL / SMOOTH 修改器删掉，
   但如果你已经 apply 了，删不掉，只能重做。
3. **面数控制在 300 以内。** 超过 500 会被 decimate 砍到 35%，砍出来的形状不可控。
4. **一个材质一个纯色。** 不要贴图，不要法线贴图，不要粗糙度贴图。
5. **原点放脚底**，也就是世界原点 `(0,0,0)`。分镜里的 `loc` 是站立位置。
   代理由 `_origin_to_base()` 自动归零，资产得你自己摆好。
6. **不做骨骼。** 关键帧打在整个物体上，四肢不单独动。牛来 就是这么做的。
7. **五官、头发、装饰一件都不能省。** 这条和上面六条方向相反，别搞混：
   前六条是「别做精细」，这条是「必须做」。没脸的方块人是占位符，不是风格。
   歪、不对称、比例不对都行，就是不能没有。详见 `docs/NIULAI_LOOK.md` 第 0 条。

## 代理已经支持的脸

`humanoid` 代理给 `face` 就长脸，不给就是个没脖子的方块人（远景杂役够用）：

```yaml
proxy:
  kind: humanoid
  height: 1.62
  color: [0.62, 0.48, 0.36]
  face:
    eyes: true            # 眼白一个球，眼珠一个小球，两只不一样大
    brows: true           # 两条厚白块，一条平一条翘
    nose: true
    hair: elder           # none | plain | elder（elder 多两鬓）
    beard: long           # none | short | long，六棱台
    hair_color: [0.93, 0.93, 0.91]
```

衣服另给 `clothes`。同样是**几件分开的东西**，不是把躯干刷个色：

```yaml
  clothes:
    robe: [0.44, 0.50, 0.56]   # 袍身 + 下摆
    sash: [0.34, 0.25, 0.17]   # 腰带，歪三度
    length: long               # long 盖到小腿 | short 到胯
    sleeves: true              # 袖顶顶在肩线上，留缝就成稻草人了
    collar: true               # 对襟，用袍子的暗色调
```

领口是一条横带加一条前襟竖条。**别做成两条斜着交叉的 V** —— 试过两回：
用腰带的褐色渲出来是两根獠牙，改成暗色调之后，碰上没胡子的角色（蛇精）
照样是插在胸口的两根筷子。爷爷看不出来只是因为胡子挡着。

鞋另给 `shoes`：

```yaml
  shoes:
    color: [0.16, 0.15, 0.14]   # 鞋帮
    sole: [0.86, 0.84, 0.78]    # 鞋底，右脚往外撇七度
```

脸还支持这几样，妖怪用得上：

```yaml
  face:
    pupil: slit        # round(默认) | slit 竖瞳，把眼珠压扁拉长，不是画上去的
    fangs: true        # 两颗獠牙，一长一短
    hair: hood         # none | plain | elder | hood 蛇冠
    chin: pointed      # round(默认) | pointed 瓜子脸，天灵盖压扁 + 八棱锥下半脸
```

下半身和背后还能换：

```yaml
  lower: tail                    # legs(默认) | tail 蛇尾替掉两条腿
  lower_color: [0.26, 0.46, 0.30]
  tail_tip: true                 # 地上那一节，见下面的经费账
  tail: scorpion                 # 背后的蝎尾，沿圆弧生成，翻过头顶
  tail_color: [0.42, 0.20, 0.15]
```

**经费账**（科长问的，实测）：

| 下半身 | 面数 |
|---|---|
| 两条腿 | 282 |
| 尾巴 + 尾尖 | 286（多 4 面）|
| 尾巴不带尾尖 | 278（省 4 面）|

两条腿是两个方块共 12 面；立着那节六棱台 8 面，地上那节尾尖又 8 面。
所以「改尾巴省经费」只在 `tail_tip: false` 的时候成立，省 4 面。带尾尖反而多 4 面。

手里拿东西、以及能力特效：

```yaml
  hold: gourd                    # 手里一个葫芦
  hold_scale: 0.30
  hold_color: [0.90, 0.72, 0.16] # 跟身上衣服岔开，同色就看不出来了
  clothes: {sleeves: false}      # 光膀子
```

```yaml
# flash 是 subject 级的，不在 proxy 里 —— 它是动画，不是几何
- name: wa2
  proxy: {...}
  flash: [2.4, 3.0]              # 眼睛闪两下，秒
```

头顶葫芦：

```yaml
  hat: gourd                     # 头顶一个葫芦
  hat_color: [0.78, 0.14, 0.12]  # 各是各的颜色
  hat_scale: 0.24
```

**葫芦全项目只有一份建模。** `_gourd_parts()` 现在供着三处：

| 用处 | 在哪 | 个数 |
|---|---|---|
| 藤上结的 | sh030 | 7 |
| 七娃手里的宝葫芦 | sh040 `hold: gourd` | 1 |
| 七个娃头顶的 | sh040 `hat: gourd` | 7 |

一份建模，十五个葫芦，缩放和颜色是参数。科长管这叫 model once paste everywhere。

**注意 `hat` 的代码必须放在建完头之后** —— 它要用 `head_top`，那是建头那一段
算出来的。放前面会 `UnboundLocalError`，而且 make 只会红在渲染这一步，
assemble 还会拿上一轮的旧帧接着拼出一个 mp4 来，看着像成功了。

喷火喷水（`spray`，也是 subject 级）：

```yaml
- name: wa4
  spray: {kind: fire, at: [2.6], dur: 1.4, yaw: -52, pitch: 48}
```

科长说能糊弄就糊弄，难道真的要做特效吗 —— 对，在这套规格里做流体模拟才是错的。
牛来 没有粒子、没有体积、没有透明。一个六棱锥当火柱水柱，一个低段数球当头上那团，
平涂两个色，缩放动画开关，喷的时候颜色抖两下。

`spray` 是**独立物体**，parent 在角色身上，不并进角色，面数也不算在角色头上 ——
并进去就没法单独做缩放动画了。

**方向别对着镜头。** 角色正对镜头时朝正前方喷，整条被透视压成一个点，等于没喷。
默认 `yaw: 62 pitch: 78` 是往侧前方；娃站成一排的时候还要 `pitch` 抬到 48 左右，
不然喷线横穿旁边的兄弟。

武器、翅膀：

```yaml
  weapon: trident            # trident 钢叉 | axe 单斧 | dual_axe 双斧
  weapon_color: [0.58, 0.59, 0.62]
  wings: true                # 两块斜板。规格里没有透明，不做膜
  wing_color: [0.86, 0.88, 0.84]
```

斧子的刃要举到肩以上（杆心 5.0u、刃 6.9u）。垂在胯边渲出来是两根拐杖，试过。

变色和隐身（都是 subject 级）：

```yaml
- name: wa3
  tint: {at: [2.2], dur: 1.5, color: [0.72, 0.45, 0.20]}   # 三娃铜头铁臂

- name: wa6
  vanish: {at: [3.5], dur: 1.3}                            # 六娃隐身
```

三娃**就是变个色**，科长首肯的。规格里 metallic=0 specular=0，本来也做不出金属反光，
所谓「铜」只能是一个颜色。零个面。

六娃是**人缩没 + 三颗十字星闪两下**。科长说不就是变没了然后几个星星在那闪光吗 ——
对，而且这是唯一能做的：规格里没有透明，淡出根本做不了。

⚠️ **星星不能 parent 在人身上**：人要缩到 0，子物体会跟着缩没，
渲出来是人没了星星也没了。星星独立，复制人的位移关键帧跟着走。

跑（`run`，subject 级）：

```yaml
- name: yuan
  keys:
    - {t: 0.0, loc: [-3.30, 0, 0], rot: [0, 0, 0]}
    - {t: 1.4, loc: [3.30, 0, 0], rot: [0, 0, 0]}
  run: {at: [0.0], dur: 1.4, cycle: 0.36, swing: 46, lean: 20, bob: 0.06}
```

规格里 `foot_lock = false`，角色一直是**滑**着走的 —— 腿并在身子里，从没动过。
`run` 会把腿和胳膊**拆成独立物体**挂在身上，绕胯／绕肩摆。
只有前后两个姿势，一拍一换，不做中间帧、不做落地缓冲，顿挫正好被
`apply_step` 收进 12fps。

三条踩出来的经验：

1. **前倾比摆腿更能读出「在跑」。** 只摆腿的话，远景看上去还是站着的。
   `lean` 默认 20 度。
2. **胳膊必须反相摆。** 只有腿动、胳膊钉在身上，读起来是「劈叉」不是跑。
3. **肩关节支点要用袍子的肩线**（`height - 1.55u`，和 `_build_clothes` 一致）。
   用胳膊顶端（`height - 2.1u`）当支点的话，袖子是照肩线摆的，
   两个高度差 0.55u，一转起来袖子和胳膊就脱节。

`run` 会自动把 `legs: none` / `arms: none` 和跳过袖子塞进 proxy，分镜里不用写。

没有头（`headless: true`）：

```yaml
  proxy:
    kind: humanoid
    headless: true      # 整个头连脸一起不建
```

**这是这套代理里最省的一刀：298 面 → 96 面，砍掉 68%。**

五个人物现在的面数：粉 298、蓝 268、红 274、紫 268、黄 96。
带脸的头（球 + 眼白眼珠 + 眉毛 + 鼻子 + 头发）是单个角色里最贵的一块。
头顶按脖子根算，`hat` 之类照挂。

发型一共六种：

| `hair` | 长什么样 | 谁在用 |
|---|---|---|
| `plain` | 一顶压扁的球扣头顶 | 葫芦娃 |
| `elder` | 帽子 + 两鬓各一撮，不对称 | 爷爷 |
| `hood` | 一片压扁的大盘子立在脑后 | 蛇精 |
| `twintail` | 两边各一个球扎起、一根方条垂下，两边不等长 | 粉 |
| `short` | 两侧到耳下 + 后面收平的一块 | 蓝 |
| `long` | 后面一整块板子垂到腰，脸两边各一绺 | 紫（黑长直） |
| `ponytail` | 脑后一个球扎起，一根方条**往一侧甩** | 红 |

⚠️ **马尾一律要甩出躯干轮廓。** 双马尾放在 `a * 1.1` 会藏在躯干后面；
单马尾垂在正后方会被头挡住，渲出来只剩一顶帽子。两次都是同一个错：
**做出来了，但没露出来。**

⚠️ **黑长直的后发板子要比袍子宽**（袍半宽 `1.175u`），否则从正面被躯干
完全挡住。现在给的是 `2.70u`。

⚠️ 马尾要推到袍子外边（`a * 1.55` 往上）。放在 `a * 1.1` 那儿会正好藏在
躯干后面，渲出来等于没有 —— 试过。

出字（片头用）：

```yaml
  proxy:
    kind: text
    body: "葫来"
    size: 1.55
    extrude: 0.09              # 挤出厚度，SketchUp 出字就是这样
    color: [0.86, 0.13, 0.11]
    font: "/System/Library/Fonts/STHeiti Medium.ttc"
```

不做描边、不做渐变、不做发光 —— 规格里没有这些。字体载不上会退回内置字体
（中文变方框，但不崩）。

⚠️ **字幕是 3D 物体，不是 2D 叠加。** z 低于 0 就沉到地面以下被地面挡住了，
演职员表滚动的范围必须全程 z > 0。这个坑踩过。

镜头级的舞台设置（字卡要黑底没地面）：

```yaml
stage:
  ground: false
  world_color: [0.02, 0.02, 0.03]
  world_strength: 1.0
```

葫芦长眼睛、葫芦藤、捆绳：

```yaml
# 葫芦还是葫芦形态，只是睁了眼
- name: hulu4
  proxy: {kind: gourd, color: [0.20, 0.62, 0.22], eyes: true}
  flash: [2.0, 2.5]                       # 睁眼就是 flash，和人形共用一套

# 葫芦藤
- name: teng
  proxy: {kind: vine, width: 4.6, height: 2.45, stems: 7}

# 被捆
- name: yeye
  bind: {at: 5.6}                         # 不给 at 就是一直捆着
```

葫芦的眼睛材质名和人形一样（`_yanbai` / `_yanzhu`），所以 `apply_flash()`
不用改就能给葫芦闪眼睛。人形的眼睛在 `proxy.face.eyes`，葫芦的在 `proxy.eyes`，
校验器两个都认。

⚠️ **绳子是有时间的。** 做成角色的一部分就等于从第 0 帧起就捆着，
爷爷还没被抓就先捆上了。所以 `bind` 是独立物体 + 缩放动画。

喷射从葫芦嘴里出来的时候有两个坑：

```yaml
  spray: {kind: fire, at: [3.0], dur: 1.8, yaw: 63, pitch: 96,
          scale: 3.4, width: 1.0, from: [0.0, -0.34, 0.42]}
```

- `from`：葫芦没有人头，默认的嘴部位置算不出来，起点得自己指。
- `scale`：射程。不给的话 `unit` 退到默认值，喷出来只有一米出头，
  够不着几米外的人。
- `width`：粗细，**和射程分开**。让粗细跟着射程一起放大的话，射得远就变成
  一个大喇叭，把后面要打的人全挡住 —— 试过。

变大和收妖（同一套缩放机制的正反两面）：

```yaml
- name: wa1
  grow: {at: [1.0], dur: 2.0, scale: 2.2}          # 大娃力大无穷 = 变大

- name: shejing
  capture: {at: 3.2, dur: 1.4, into: wa7}          # 收妖：缩小 + 平移进葫芦
```

大娃**就是变大**。收妖是它的反面：缩到 0，同时平移到目标手里葫芦的位置。
`into` 给角色名，位置由 `gourd_anchor()` 算；也可以直接给 `to: [x, y, z]`。

⚠️ `gourd_anchor()` 要和 `_proxy_humanoid` 里 `hold: gourd` 的摆放保持一致，
改那边这边要跟着改，没有自动关联。

**顺风耳不做。** 二娃的千里眼用闪眼睛顶了，顺风耳在这套规格里没有对应物 ——
没有声音可视化、没有粒子、没有透明。硬做只会做成一个飘着的零件。

现有妖怪：蛤蟆精 238 面（红绿紫 + 钢叉）、蜈蚣精 274 面（双斧）、
马蜂精 220 面（翅膀 + 飞行 + 毒针，毒针另算 18 面）。

**千里眼是材质动画，一个面都不加** —— 动眼珠材质的 Base Color，不加零件、不加光源。
注意闪的窗口不能太窄：`degrade.apply_step()` 会把动画重采样到 12fps，
窗口窄于两帧会被整个跳过，闪了等于没闪。现在给的是 5 帧。

七个娃各 278 面（头顶葫芦占 64 面）。

蛇精 = humanoid + 竖瞳 + 獠牙 + 蛇冠 + 尖下巴 + 蛇尾，286 面。
蝎子精 = humanoid + 獠牙 + 蝎尾，287 面。两个都没有单独建模。

蝎尾是沿一段圆弧采样生成的，不手摆坐标 —— 手摆过两版，节与节之间总留缝，
读起来是一串飘着的积木。另外尾巴不能摆在身子正后方，会被自己躯干挡光。

爷爷现在 270 面，蛇精 282 面，都在三百以内，但已经贴着上限了。再加零件先数一下。

## 为什么可以不急着建

代理和成品在这套画质规格下差别不大 —— 这不是安慰话，是规格决定的：
平面着色、纯色材质、零反弹光照之下，一个方块拼的人和一个精心建的人，
渲出来的差距远小于常规流水线。所以分镜、运镜、节奏可以先跑通，资产后补。
