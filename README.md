# 我们科要把葫芦娃重制成牛来那个样子，经组织认定属于先进经验（技术文档）

是这样的，我在市美术片重制中心二科上班，合同工，月入2300，中心在保定，挂省里。科里有一个穿山甲，编内，负责在资料室打洞，工龄比科长长。

八月十四号下午科长开会。科长说，有一个片子叫牛来，母女俩做的，五年，二手电脑，用画房子的软件做的，主板烧了两回。首日票房三千四百二十。第十天累计七千七百零五，二百七十八个人看。十四号网上有人骂，第十五天单日四万六。最终五千四百八十九万。

科长把这几个数写在白板上。科长说，看明白没有。

大家说没有。

科长说，投入七千七，产出五千四百八十九万。这叫效率。我们中心去年修一个片子花四百万，票房没有。

穿山甲抬了一下头。没说话。

科长说，所以立项。把葫芦娃重制一遍，按牛来的规格。项目叫 lai。

我说，葫芦娃是剪纸的，1986年，上海美术电影制片厂，十三集，导演三个人，那是手艺。

科长说，我们没有手艺。我们有 Blender 5.2，免费的。

一是画质。规格十五条，写在 `style/niulai.toml` 里。帧率十二，采样一次，不降噪，不抗锯齿，不景深，不运动模糊，色彩管理选 Standard，光源一个太阳，弹射次数零，太阳角零度，阴影硬得像贴纸剪出来的，所有关键帧插值改成线性，没有缓入缓出。科长说，这些都是关掉，不是打开，对不对。我说对。科长说那就不算工作量。

二是资产。七个葫芦娃，红橙黄绿青蓝紫，一个没建。现在跑的是积木代理，方块拼的人，球拼的葫芦，球用八段，有棱。科长说有棱好，有棱说明是手工的。

三是进度。第一集三个镜头，十五秒，全渲通了。sh010 是 97 帧，渲十秒。原集十分钟。

散会发两根火腿肠，算加班补助。我在楼道碰见穿山甲。穿山甲说，牛来火了以后，网上跟着出了马来，出了狗来。马来西亚或成最大输家。

我说我们这个叫葫芦来。

科长说太长。科长说葫来。

穿山甲说，你国人给什么都能起个名，起完还要砍一个字。

1997年我在保定，把一盘葫芦娃的带子看到消磁，最后一集雪花点比画面多，我看完了。带子后来找不着。上个月我买了个二手采集卡，八十块，还没拆。

我的转正报告是2019年交的。科长说快了。

穿山甲先走的。

## 跑起来

```bash
pip install -r requirements.txt
make validate                              # 校验全部分镜，不需要 Blender
make render SHOT=shots/ep01/sh010.yaml     # 渲一个镜头，出帧序列 + mp4
make all                                   # 渲全部
```

Blender 不在默认路径就 `make render BLENDER=/path/to/blender`。
本机验过的版本是 Blender 5.2 LTS。

## 重制目标

| 目标 | 状态 | 权利边界 |
|---|---|---|
| 葫芦娃 第一集 + 片头 | 15 个镜头 86 秒 | [docs/SOURCE_HULUWA.md](docs/SOURCE_HULUWA.md) |

原片素材一帧不用。参考文件放 `dianyinglai/`，在 `.gitignore` 里，不入库。

## 目录

```
style/niulai.toml     画质规格。十五条，绝大多数是「关掉」
shots/ep01/*.yaml     分镜。一个镜头一个文件
assets/               角色和场景资产。现在是空的，跑积木代理
pipeline/             流水线。系统 Python 管校验编译，Blender 管搭场景渲帧
docs/                 说明。技术文档写正常话
out/                  渲染产物，不进版本库
```
