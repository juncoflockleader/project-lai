# 关于葫芦来项目分阶段推进的实施安排（内部，勿外传）

经组织认定，本项目分四个阶段。以下为科长在八月二十八号例会上的原话，我记的，
错字是我的。会上发了拍黄瓜，一人一碟，凉的。中心在保定，挂省里。我合同工，月入2300，负责记录，记错了算我的。

## 第一阶段：把管子打通（已完成）

科长说，先不管好看不好看，先让它出得来。

一是画质规格立起来了，十五条，在 `style/niulai.toml`。十四条是关掉，一条是打开。
二是流水线通了。`shots/*.yaml` → 编译 → Blender → 帧 → mp4，一条龙。
三是第一集三个镜头渲通了，一共十五秒，363 帧。sh010 是 97 帧，渲十秒。大家说这个快。
四是校验器有了，CI 上跑，不用装 Blender。
五是资产一个没有，跑积木代理。方块拼的人，球拼的葫芦。

科长说，五分之四完成，这个说法不严谨，对不对。

科长说，但是可以这么写。

## 第二阶段：把人建出来

一是七个葫芦娃，红橙黄绿青蓝紫，一人一个 `.blend`。
二是爷爷、穿山甲、蛇精、蝎子精，四个。
三是面数每个压在三百以内，超过五百会被砍到百分之三十五，砍出来什么样不好说。
四是不许倒角，不许细分，不许贴图，不许骨骼。约束写在 `assets/characters/README.md`。
五是原点放脚底。这条上礼拜栽过一回，代理的原点在头上，人全埋地里了，
    修在 `build_shot._origin_to_base()`。

科长说，哪能。建模这个事，谁建谁负责，建丑了不算事故。

我说，建好看了算不算事故。

科长说，算。

## 第三阶段：把第一集配全

一是分镜从三个镜头补到整集。原集十分钟，重制不追求等长，多长算多长。
二是台词要录。录音不做响度归一，忽大忽小是特征，写在 `[audio].normalize = false`。
三是口型接上。现在是整个身子在 Z 轴上抖百分之三，读作在说话，
    等嘴单独建出来再改 `build_shot.apply_lipsync()`。
四是运镜校验。规格只准静止、直线推、直线摇三种，现在靠人守，校验器还不管。
五是山要裂开。原片有碎块有烟有光效，我们让整块山往下沉，不补。

## 第四阶段：剩下十二集

科长说，是这样的，第四阶段先不细化。你国人做事，做完第一步再说第二步。

科长说，先把第一集做出来，做出来再说。

科长说，1986年做这个片子的时候，一集要磨很久，三个导演。我们三个人，
一个是穿山甲。

穿山甲在桌子底下。没参加。

## 不做的事

一是不做修复版，不冒充官方。
二是不用原片的画面、音频、美术资产。
三是不做复古滤镜、扫描线、VHS，那是加，方向反了。
四是不把 bug 当风格。穿模破面渲染报错要修，同一个分镜渲两遍得一模一样。

第一条到第四条，写在 `docs/SOURCE_HULUWA.md` 的权利一节，那份是正常话写的。

散会。拍黄瓜没人动，放到第二天，第二天倒了。

我的转正报告没提。会议记录一共四页，我排的版。
