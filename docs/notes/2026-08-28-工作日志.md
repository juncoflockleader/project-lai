# 工作日志

是这样的，葫来上映了，票房 4 人次，全是科里的。我合同工，月入2300，票钱自理。老张一张，老张媳妇一张，我一张，穿山甲一张。穿山甲那张是老张替它买的，它没去，它说它在打洞。

科长说，四人次，这个数不好看。

我说，还有老王没来。

科长说，老王是老张媳妇。

我说，那老张媳妇不是来了吗。

科长说，来了，不舒服，中途走了，算半张。

科长把四改成三点五，又改回四。科长说票房这个东西不能往下改，往下改是事故，对不对。

科长看了样片。科长说，你们做的是个什么玩意嘛。科长说，来来来。

科长下载了一个电影，日本的，昨天上映，俗称马猴烧酒。科长说这个东西仅限学习参考，看到了吗，二十四小时以内删除。

我把它加进了 gitignore。仓库是公开的，八点八兆，一次手滑就推上去了。

科长说加什么加，二十四小时就删。

我说二十四小时里也能推上去。

科长说那你加吧。

片头九十秒，二十九个镜头。剪辑点我量了五十二个。第一版量出来是零个，两部片子都是零个，我拿着这个零写了一段结论，说这片子没有硬切。后来发现是我自己把日志级别调低了，检测结果全被吞了。零不是片子的零，是我的零。

科长说那你之前那段话怎么办。

我说我更正了。

科长说更正也要归档。

黄头发那个没有头。科长说他记得就是没头，去了还省钱。我数了一下，298 面变 96 面，省 68%。一个带脸的头是全项目最贵的一块，比一整套衣服还贵。科长说哪能。科长说早说啊。

双马尾第一版看不见。我把它放在了身子后面，渲出来什么都没有，往外挪四厘米就有了。这种错我这个月犯了四次，都是同一个：东西做出来了，但是没露出来。

散会发火腿肠，一人两根。穿山甲不吃，它把它那两根埋了。

1997年夏天我在保定，电视里放过一个动画片，七个小孩从藤上掉下来。我姐说这个太吵，把电视关了。她现在在廊坊卖保险，上个月打电话问我买不买。

我的转正报告是2019年交的，今天第二千五百五十七天。

穿山甲的洞打通了，通到财务科。
