# 为什么是葫芦娃

资料室。下午四点。穿山甲在打洞。穿山甲编内，副科级待遇，比我高两级。我合同工，月入2300。

我说，为什么是葫芦娃。

穿山甲说，因为它是剪纸的。

穿山甲说，剪纸这个东西，平的，镂空的，一层一层摞着，全靠美术设计撑住。你把它推成三维低模，丢掉的正好是它唯一赖以成立的东西。

我说，那不就毁了。

穿山甲说，对。

穿山甲用前手扒了一下土。

穿山甲说，牛来那个片子，两个人，五年，没受过训练，用画房子的软件。全网骂了半个月，票房从三千四百二十涨到五千四百八十九万。你说那些人冲什么去的。

我说，冲难看。

穿山甲说，不是。冲手印。

我下午吃了两个茶叶蛋，门口那家，五块钱两个，保定这边都是这个价。前年三块。

穿山甲说，现在的片子都很顺，顺得看不出人在哪儿。牛来不顺。每一帧都能看见那两个人坐在二手电脑前面一格一格打关键帧，主板烧了两回。看的人认这个。

我说，所以我们是要难看。

穿山甲说，不是要难看，是要不藏。抗锯齿是藏，景深是藏，运动模糊是藏，全局光照是藏，降噪是藏。藏的全关掉，剩下什么就是什么，对不对。

穿山甲说，十五条规格，十四条是关掉。

我说，那一条呢。

穿山甲说，帧率。把动作重采样成一格一格蹦的，代码在 `pipeline/degrade.py` 里，函数叫 apply_step。这一条是加上去的，加了才像手打的。别的都是拆。

我说，穿模呢，破面呢，渲染报错呢。

穿山甲说，哪能。那是 bug，不是风格。同一个分镜渲两遍，出来得一模一样。做不到就不是规格，是运气。

我说，葫芦娃的观众怎么办。

穿山甲说，葫芦娃的观众现在四十多了，秃了，在开会。他们不看这个，他们转发这个。

穿山甲说，1986年做这个片子，一集要磨很久。我们现在一个镜头渲十秒。省下来的时间去哪儿了，没人说得清。

洞打到墙那边是财务科。财务科去年问过中心一句话，问修一个片子四百万，看的人多少。中心回了一份材料，十七页，没有回答这个问题。

我的转正报告排在第十八页。材料是我自己排的版。

穿山甲把洞又往里打了两公分。
