# 参考源二：魔法少女小圆 片头

## 基本信息

| | |
|---|---|
| 作品 | 魔法少女まどか☆マギカ |
| 年份 | 2011（TV），剧场版另计 |
| 参考的部分 | 片头，约 89.8 秒 |

## 从它那里取了什么

**只有节拍和时长。** 用 ffmpeg 量出剪辑点，得到这个结构：

| 段 | 时间 | 特征 |
|---|---|---|
| 开场特写 | 0–8.4 | 四个切，间隔递减（3.6 / 2.3 / 1.7 / 0.8） |
| 片名 | 8.4–10.4 | 一个定版 |
| 长镜头段 | 10.4–55 | 单镜头 9–13.6 秒，职员字幕叠加 |
| 快切爆发 | 55–77 | 最短切点间隔 0.1 秒 |
| 出品字幕块 | 77–86 | 静止 |
| 片尾定版 | 86–89.8 | 片名再出一次 |

这个「慢开场 → 长镜头 → 快切爆发 → 收」的骨架，和《葫芦兄弟》片头
（基本是固定构图配滚动字幕）完全不同，是值得学的东西。

## 没有取什么

1. **不用原片的任何画面、音频、美术资产。** 一帧都没有。
2. **不用主题曲。** 一秒都没有，歌词一个字都没有。
3. **片名是我们自己的**（《圆来》，黑体挤出厚度），不是原片的标题设计。
4. **职员表是我们自己的**（科长、合同工、穿山甲）。
5. **角色是我们自己的低模**：五个人物用五种标志色 + 双马尾，
   这是这类作品的通用配置，我们的实现是方块和球拼的。
