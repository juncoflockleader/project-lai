## 一条更正

上一版曾断言葫芦兄弟片头「场景检测一个切点都没检出」。那是**测量方法坏了**：
`ffmpeg -v error` 会把 `showinfo` 的 INFO 级输出整个吞掉，任何片子都返回零。
改用 `metadata=print` 之后，圆来片头检出 52 个切点。零结果要先怀疑方法。
